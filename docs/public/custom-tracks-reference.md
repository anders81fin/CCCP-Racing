# Custom track reference

Generated by `--track-schema` from the game's own track definition: do not edit by hand (a test keeps this file equal to the game's output). What the fields mean, and how to build a good track, is in [custom-tracks.md](custom-tracks.md).

A track is one JSON file; comments (`//`) and a trailing comma are allowed. Unknown or misspelt fields are errors.

These are all the top-level fields a custom track may set. The campaign tracks use more (water, snow banks, the camp, the radiation, the airbase, the norms...); they are refused in a custom track. `id` is ignored: the game uses the folder name.

### Limits

File at most 512 kB; map size x tileSize is the square the road and props must stay inside; every x and z keeps 14 m from the map's edge (props 2 m).
