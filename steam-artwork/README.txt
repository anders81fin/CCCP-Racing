CCCP RACING — STEAM CUSTOM ARTWORK
=================================

SUOMEKSI

Lisää peli Steamissa: Pelit > Lisää muu kuin Steam-peli omaan kirjastoon.
Valitse CCCPRacing.exe (Windows), CCCPRacing.x86_64 (Linux) tai pelin
.app-sovellus (macOS). Pura koko pelipaketti ennen lisäämistä.

Kuvat valitaan Steamin työpöytätilassa. Steam Deckillä vaihda ensin
työpöytätilaan. Valikkojen nimet voivat vaihdella käyttöliittymän kielen mukaan.

1. Pystykansi: library-cover-600x900.png
   Kirjaston etusivu/kokoelma > pelin pystykortin oikea napsautus >
   Hallitse > Aseta mukautettu kuvitus (Set custom artwork).

2. Vaakakansi: library-wide-920x430.png
   Käynnistä ja sulje peli kerran, jotta se näkyy viimeksi pelattuna.
   Valitse viimeksi pelatun pelin leveän kortin oikealla napsautuksella
   Hallitse > Aseta mukautettu kuvitus. Tämä on erillinen kuva pystykannesta.

3. Pelisivun taustakuva: library-hero-3840x1240.png
   Avaa pelin sivu kirjastossa. Napsauta sivun yläosan leveää taustaa oikealla >
   Aseta mukautettu tausta (Set custom background).

4. Taustakuvan päälle tuleva logo: library-logo-1280x720.png
   Napsauta samaa yläosan taustaa oikealla > Aseta mukautettu logo
   (Set custom logo). PNG:n tausta on läpinäkyvä.
   Säädä tarvittaessa logon paikkaa ja kokoa (Adjust logo position).

5. Pieni kuvake: game-icon.ico (Windows) tai game-icon-512.png (Linux/macOS)
   Pelin oikea napsautus kirjaston listassa > Ominaisuudet > Pikakuvake.
   Napsauta pelin nimen vieressä olevaa pientä kuvaketta ja valitse tiedosto.
   ICO sisältää 16, 24, 32, 48, 64, 128 ja 256 pikselin versiot.

Kuvien asetus on Steam-pikakuvakekohtainen. Pelin lisääminen ei aseta näitä
automaattisesti. Säilytä steam-artwork-kansio pelin vieressä, jotta tiedostot
ovat helposti löydettävissä myös myöhemmin.

ENGLISH

Extract the complete game package, then choose Games > Add a Non-Steam Game
to My Library. Select CCCPRacing.exe, CCCPRacing.x86_64 or the macOS .app.
Use Steam's desktop interface (Desktop Mode on Steam Deck) to set artwork:

File                           Where to select it
-----------------------------  ---------------------------------------------
library-cover-600x900.png       Library Home/collection: right-click the
                               portrait tile > Manage > Set custom artwork.
library-wide-920x430.png        Launch and close once. Right-click its wide
                               Recent Games tile > Manage > Set custom artwork.
library-hero-3840x1240.png      Game library page: right-click the top banner
                               > Set custom background.
library-logo-1280x720.png       Same banner > Set custom logo. Transparent PNG;
                               use Adjust logo position to size/place it.
game-icon.ico                  Game Properties > Shortcut: click the small
game-icon-512.png              icon beside the name. ICO for Windows;
                               PNG for Linux/macOS.

Steam keeps artwork per shortcut. Adding the game does not automatically
install these images. Keep this folder beside the game for easy access.

Library asset dimensions:
https://partner.steamgames.com/doc/store/assets/libraryassets
Non-Steam custom artwork locations:
https://hamatti.org/snacks/steam-custom-sizes/

Artwork adapted from the CCCP Racing cover and banner.
